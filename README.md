# StackIt  

**StackIt** is a minimal **Question-and-Answer (Q&A) platform** that supports **collaborative learning** and **structured knowledge sharing**.  
It’s designed to be **simple, user-friendly, and focused** on the core experience of asking and answering questions within a community.  

---

## 🚀 Features  
- 📝 Ask questions and share knowledge  
- 💬 Post answers with a clean interface  
- 🔑 User authentication (login/register)  
- 🎨 Styled with modular CSS files  
- ⚡ Dynamic interactions with JavaScript  
- 🗄️ PHP backend with database connectivity  

---

## 📂 Project Structure  

│── app/ # Backend (views, forms, etc.)
│── css/ # Stylesheets
│── includes/ # Config & database connection
│── js/ # JavaScript logic
│── public/ # Public PHP pages (entry points)
